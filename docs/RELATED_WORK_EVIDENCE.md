# Related-Work Evidence Package

## Purpose

`related_work/table_I/` contains the audit material used to support the representative-work comparison reported in Table I of the manuscript. It is included so reviewers can inspect how each check mark and blank entry was assigned.

## Contents

- `table_I_final_matrix.xlsx` and `.csv`: final comparison matrix used for Table I.
- `table_I_evidence_log.xlsx` and `.csv`: criterion-level evidence recorded for the reviewed works.
- `table_I_source_index.xlsx` and `.csv`: mapping between table entries and the corresponding DOI/source records.
- `Table_I_Audit_Combined.xlsx`: consolidated workbook for reviewer inspection.
- `README.md`: interpretation rule used by the audit package.

## Verification rule

A check mark is used only when the corresponding element is explicitly reported in the reviewed paper. A blank cell means that the element was not explicitly identified in the focused review used to populate Table I; it is not automatically a negative assessment of the cited work.

The package preserves source/DOI mapping and criterion-level evidence. It does not include copies of the cited articles. Reviewers can use the source index to consult the original publications independently.

## Relation to the manuscript

This material supports the related-work comparison only. It is separate from the model-training, Python--firmware conformance, energy, latency, memory, and hardware evidence used in the experimental sections.
